# Academic task one algorithm
1. Paraphrase the question. Paraphrase the question of the task and use it to start your essay
2. Write an overview. The overview should contain a short summary of the data shown in the chart. It should not include any exact figures or metrics, but rather should provide clear and distinct information about the chart. The length of the overview should be around 30 WORDS. 
3. The first body paragraph should contain more concrete information about the topic and the figures. Overall, the analysis in this part of the essay should be more precise, using specific data

### Common tips
#### Paraphrasing 
The best way to paraphrase is to change the words correctly. The second-best way is to just copy them. The worst way to paraphrase is to change the words incorrectly
##### Common vocabulary for paraphrasing
Table - Chart
Shows - Illustrates/Demonstrates
Percentage - Proportion/figures/rates
Countries - Nations
